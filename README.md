# AccessPath Jobs

Build Phase 1 of AccessPath, an accessibility-first job marketplace specifically designed for visually impaired job seekers and transgender job seekers in India.



AccessPath should feel like a focused version of Naukri/Indeed, but with accessibility and inclusion built into the core job-search experience.



The primary goal is:



Find suitable jobs → understand accessibility → decide whether to apply.



Do NOT make learning/skill development the primary feature.



---



1. PRODUCT DESIGN



Create a professional Indian job-platform experience.



The design should feel like a real employment platform, not a charity website.



Important:



Do NOT portray visually impaired or transgender users as helpless.



Use empowering language such as:



- Find opportunities

- Build your career

- Discover inclusive employers

- Apply with confidence



Do not require users to disclose disability or gender identity.



Identity information should be optional and privacy-conscious.

7. ACCESSIBILITY-FIRST UI



This is one of the main differentiators of AccessPath.



Implement:



High Contrast Mode



Allow users to switch between standard and high-contrast mode.



Font Size



Small / Medium / Large



Keyboard Navigation



Every major function must work using keyboard navigation.



Screen Reader Support



Use:



- Semantic HTML

- ARIA labels where required

- Accessible buttons

- Meaningful form labels

- Proper heading hierarchy



Focus Indicators



Clearly show which element is currently focused.



Reduced Motion



Respect the user's reduced-motion preference.



---



8. VOICE JOB SEARCH



Add a microphone button to the search bar.



Example:



User says:



"Find remote software developer jobs in Chennai."



Convert speech to text and search the job database.



Also allow:



"Find fresher data analyst jobs."



Keep the implementation simple.



If browser speech recognition is unavailable, gracefully fall back to normal text search.



---



9. TEXT-TO-SPEECH



Add a speaker button to job descriptions.

Allow:

Stop



This should be especially useful for visually impaired users.
